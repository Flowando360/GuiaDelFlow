MÉTODO TÉCNICO OBLIGATORIO — sigue estos pasos exactamente:
1. Genera cada una de las 5 páginas como un HTML independiente con WeasyPrint.
2. Cada HTML tiene su propio @page { size: 8.5in 11in; } con los márgenes que correspondan.
3. La portada usa margin: 0 y min-height: 100vh con flexbox para distribuir el contenido.
4. Las páginas internas usan margin: 0.55in 0.65in 0.55in 0.65in con @bottom-left y @bottom-right para los footers: 'CARTA PARA [NOMBRE]' y 'FLOWANDO · 2026'.
5. Cada página se convierte en un PdfReader con pypdf.
6. Tomas SOLO la primera página (reader.pages[0]) de cada uno.
7. Los unes todos en un PdfWriter y escribes el archivo final.
8. Verificas visualmente con pdftoppm todas las páginas antes de entregar.
Este método es obligatorio porque si usas un solo HTML largo con page-break-before: always, el texto se corta entre páginas y las imágenes quedan solas en páginas vacías.
